# Product Category Project

## Описание

Проект реализует систему категорий и товаров интернет-магазина.

Реализованы классы:

- Product
- Category

## Функциональность

- создание объектов Product;
- создание объектов Category;
- подсчет количества категорий;
- подсчет количества товаров;
- тестирование через pytest;
- проверка покрытия pytest-cov;
- проверка стиля flake8.

## Технологии

- Python 3.13
- Poetry
- Pytest
- Pytest-cov
- Flake8
- Black
- Isort
- Mypy

## Обработка исключений при создании товара

В классе Product реализована проверка количества товара при создании объекта.

Если количество товара меньше или равно нулю, выбрасывается исключение:

ValueError("Товар с нулевым количеством не может быть добавлен")

Это предотвращает создание товаров с некорректным количеством на складе.

Подсчет средней цены товаров

В классе Category реализован метод average_price(), который вычисляет среднюю цену всех товаров категории.

Метод:

суммирует цены всех товаров;
делит сумму на количество товаров;
возвращает среднюю цену.

Если в категории отсутствуют товары, метод возвращает 0 без возникновения ошибки.
